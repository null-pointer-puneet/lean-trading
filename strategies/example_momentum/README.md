# Example: SMA Crossover on SPY

Classic 20/100 SMA crossover on SPY at daily resolution.

- **Entry**: Go long 100% of portfolio when the 20-day SMA crosses above the 100-day SMA.
- **Exit**: Liquidate when the 20-day SMA crosses back below the 100-day SMA.
- **Universe**: SPY, daily bars.
- **Warmup**: 100 days for the slow SMA indicator.

This is a demo strategy for the workflow. Tune, extend, or replace.
